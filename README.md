# 《神话》· MYTHOS MAGAZINE
## 中华神话重构系列 · 30期独立数字文学杂志（Awwwards / Webby / FWA 获奖品质标准）

本项目将作者原创的「中华神话重构系列」小说全集（共 30 期，14.3 万字，哪吒篇已按要求永久排除）完整制作成一本具备国际设计大奖（Awwwards / Webby Awards / FWA Site of the Day）标准的独立数字文学杂志网站，对标 [daozhuai.cn](https://www.daozhuai.cn) 与 [aifa.one](https://www.aifa.one/)。

### 一、品质标准与核心设计体系

1. **Awwwards 级排版与视觉语言 (Aesthetic Standards)**
   - **全站宣纸肌理 (Song Dynasty Xuan Paper Grain)**：通过内联高精度 SVG 杂色噪点滤镜与 `mix-blend-mode` 混合，赋予界面宋代手造宣纸的微观物理触感。
   - **磁性流体光标 (Magnetic Fluid Cursor)**：桌面端具备自适应惯性追踪红点与金色光环，在悬浮期刊卡片及封面时动态膨胀并呈现「翻阅」微动效；触摸端自动休眠。
   - **双色温典藏体系**：
     - **日间模式**：古籍暖米纸色（`#fafaf7`）、徽墨色文字（`#111418`）、朱砂红印章（`#b23a2b`）、老金滚边（`#b08d57`）。
     - **夜间模式**：幽冥玄青墨岩（`#161513`）、温润宣纸墨字（`#e8e5dc`）、暗金流光（`#d6b77e`）。

2. **100% 专属精确配图 (100% Verified Bespoke Artworks)**
   - 全书 30 篇小说**每一篇均配备对应专属大画幅原画**，彻底杜绝图文不符或无图现象。
   - 包含针对《白蛇·雷峰塔》《苏妲己》《孟姜女哭长城》《孟婆汤》《尾生抱柱》《混沌之死》《画龙点睛》《烂柯人》《聊斋·画皮》《白水素女》《神农尝百草》《倩女幽魂》《干将莫邪》特别创制的 13 幅 16:9 极高精度水墨重构艺术巨作。

3. **全画幅沉浸视界杂志阅读器 (Full-Bleed Magazine Reader Engine)**
   - **全屏全画幅封面 (Full-Bleed Cover)**：大图铺满整个视口，带有慢速电影级 Ken Burns 镜头推近呼吸感、朱砂红报头印章、大幅衬线标题、原典出处。
   - **原典题记页 (Colophon & Inscription)**：金印居中，大号引言名句，直击灵魂。
   - **正文章节跨页 (Editorial Chapters)**：专属场景宽画幅原画 + 金线小标图注 + 杂志金句引文卡片 + 双栏报刊优雅排版 + 首字下沉（Drop Cap）。
   - **顶栏阅读进度条 (Reading Scrubber Bar)**：极细金红双色流光进度条，实时显示阅读百分比。
   - **双药丸毛玻璃悬浮控制台 (Frosted Glass Isle Controls)**：
     - 左岛：字号缩放（A-/A+）、日夜模式（D）、目录抽屉（T）、上一页/下一页、页码跳转。
     - 右岛：一键分享/复制链接、收藏至藏书阁、真实翻页声音效切换、全屏沉浸（F11）。
   - **自研 Web Audio API 拟真翻页音效**：零外部音频文件依赖，毫秒级合成真实宣纸翻折沙沙摩擦声。

4. **五大卷册报纸归档与实时检索 (Sections & Search Archive)**
   - **卷一 · 创世与洪荒**（仓颉造字、混沌之死、神农尝百草、女娲造人与补天、大禹治水）

### 二、本地运行与极速启动

项目没有任何复杂后端或 Node 构建链依赖，纯原生现代现代 Web 技术栈（Vanilla JS + CSS Custom Properties + Web Audio）：

```bash
# 进入项目目录
cd /Users/gx/.gemini/antigravity/scratch/myth-magazine

# 启动本地开发服务 (支持端口 3456)
./start.sh
```

打开浏览器访问：`http://127.0.0.1:3456` 即可全屏沉浸体验。

### 三、独立网站上线与部署指南（对标 daozhuai.cn）

本项目已完全解耦且自包含，包含 `_redirects`、`vercel.json`、`robots.txt`、`sitemap.xml`，可在 1 分钟内完成全网独立上线：

#### 方案 A：Cloudflare Pages（推荐，与 daozhuai.cn 相同部署方式）
1. 在 GitHub 上新建仓库，将当前目录全部文件推送至 GitHub：
   ```bash
   git init
   git add .
   git commit -m "feat: release mythos magazine v1.0"
   git branch -M main
   git remote add origin <你的Github仓库URL>
   git push -u origin main
   ```
2. 登录 [Cloudflare Dashboard](https://dash.cloudflare.com/) -> **Workers & Pages** -> **Create application** -> **Pages** -> **Connect to Git**。
3. 选择该仓库，Framework preset 选择 **None**，Build output directory 填写根目录 `.`，点击 **Save and Deploy**。
4. 绑定自定义域名（例如 `myth.daozhuai.cn` 或独立域名），即刻享有全球 CDN 与 SSL 加速。

#### 方案 B：Vercel / Netlify
- 仓库内已内置 `vercel.json` 与 `_redirects`，直接 Import 仓库即可 0 配置上线。
